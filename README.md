# Casa María Madre – Reservas

App web instalable (Android / iPhone) para gestionar las reservas y la ocupación de la Casa de Espiritualidad María Madre (Guadalajara).

- Dirección: https://casamariamadre.github.io/reservas/
- Los datos están en Google Sheets y Google Calendar, a través de un Google Apps Script de la cuenta de la casa.
- Configuración en `config.js`.
